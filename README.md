# Circular Garden

## Description
This program lets the user input a number, then, using that number, it finds the area, circumference, and square root. Along with that, it also prints out the number rounded up and down.

## How to Run
- Open the code in Python
- Run the Python file
- Input the desired numbers

## Input Needed
- Radius of the garden

## Sample Output
import math

# --- Circular Garden ---

    Circumference of the garden: 420.97 meters

    Square root of the area: 118.75

    Area rounded down: 14102.00 square meters

    Area rounded up: 14103.00 square meters
